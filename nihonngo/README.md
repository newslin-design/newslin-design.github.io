# かん字れんしゅうシート

漢字書寫練習單。純 HTML / CSS / JS，沒有建置步驟，直接開檔就能用。
版面規格（A4 794×1123px、配色、格線）逆向自原本的 `kanji_worksheet_1_2.pdf`。

目前收錄：

| 練習單 | 內容 |
|---|---|
| れんしゅう ⑥ / ⑦ | 小學一年級：一・二 ／ 三・四 |
| N3 ① / ② | JLPT N3：経・験・報・告 ／ 変・化・増・減 |

## 怎麼用

- 直接用瀏覽器開 `index.html` → 選一張練習單。
- 或直接開 `sheet.html?id=g1-06`。
- 想一次印好幾張：`sheet.html?id=g1-06,g1-07`（逗號分隔，每張自動分頁）。

控制項在**左側欄**（螢幕寬度 980px 以下會收起來，用左上角的 ☰ 拉出，
點遮罩、按 Esc 或選完一個按鈕都會自動收回）：

| 開關 | 作用 |
|---|---|
| れんしゅう | 換一張練習單 |
| モード | 三選一，見下表 |
| 描紅 | 淡灰範字的濃度：濃い／うすい／なし |

三種模式：

| モード | 用途 |
|---|---|
| **いんさつ（白紙）** | 預設。什麼都不互動，印出來就是給學生手寫的空白卷 |
| **れんしゅう** | 學生自己作答：大題 1・4 直接在田字格上寫字，大題 2 打假名，大題 3 點格子選字 |
| **こたえ** | 答案直接印在題目上，就是老師的解答卷 |

### れんしゅう 模式

- **寫字**：大題 1・4 的格子可以用滑鼠／手指／觸控筆寫，有壓感的筆會有粗細變化。
  單格右上角的 × 清那一格，工具列的「ひとつ もどす」撤銷最後一筆。
- **筆順チェック**：寫完一筆會跟正解比對，寫錯順序、方向寫反、畫數超過時會跳提示。
  刻意做得寬鬆——字寫歪不會叫，只有明顯搞錯順序才出聲。
- **まるつけ**：批改並算分。分數填進「てん」欄，80 分以上蓋「よくできました」。
- **やりなおす**：清空所有答案與手寫。

計分方式：每一題平均分配該大題的分數（答對 3/4 就拿 3/4 的分），
最後換算成百分制——原教材寫「80てんいじょうで」，但三個大題加起來只有 40 分，
不換算的話那條線會對不起來。想改成「ぜんぶできて才給分」，
改 `js/quiz.js` 的 `scoreSection()` 一行就好。
大題 1 的 20 分是「每一格都寫過」才給。

### 筆順動畫

三種模式下都可以用。點大題 1 的紅色範字（或大題 4 左邊的字），會跳出視窗一筆一筆播給你看，
下面附「一畫一格」的筆順表。有 `ゆっくり`（放慢）和 `ばんごう`（筆序號碼）兩個開關。
按 Esc 或點背景關閉。

沒有筆順資料的字不會有任何互動，範字就只是普通的字。

### 線條粗細

筆順動畫和手寫筆的線寬都**隨畫數自動變細**，不然像 `験`（18 畫）會糊成一團：

| 字 | 畫數 | 手寫筆寬（53px 格） |
|---|---|---|
| 一 | 1 | 6.9px |
| 四 | 5 | 5.1px |
| 経 | 11 | 3.6px |
| 験 | 18 | 2.7px |

要調整就改 `js/trace.js` 的 `penWidth()` 和 `js/stroke.js` 的 `inkWidth()`。

### 列印成 PDF

按工具列的「印刷 / PDF に保存」，在列印視窗裡：

- 紙張 **A4**
- 邊界 **無 (None)** ← 版面自己留好邊界了
- 勾選 **背景圖形 (Background graphics)** ← 沒勾的話藍色橫幅和淡灰描紅字會印不出來
- 取消 **頁首及頁尾** ← 否則會多出網址和日期
- 目的地選「另存為 PDF」

## 怎麼加新的練習單

HTML 和 CSS 都不用動，只改 `data/` 底下三個地方。

### 1. `data/kanji.js` — 漢字字庫

一個字寫一次，之後所有練習單都能重複引用：

```js
"三": {
  strokes: 3,                    // 畫數 → 顯示成「3かく」
  yomi: "さん‧みっつ",            // よみかた 欄
  examples: [                    // つかいかた 欄
    { w: "三月", r: "さんがつ" },
    { w: "三人", r: "さんにん" }
  ]
}
```

筆順不寫在這裡，它在 `data/strokes.js`，用下面第 3 步的工具產生。

`grade` 可以是數字（日本小學年級，顯示成「1年生」）或字串（`"N3"`，照原樣顯示）。

### 2. `data/sheets/<id>.js` — 一張練習單

`sections` 是陣列，**順序就是版面順序**，數量不限：

```js
window.SHEETS = window.SHEETS || {};
window.SHEETS["g1-07"] = {
  id: "g1-07",
  grade: 1,
  label: "れんしゅう ⑦",
  brand: "1年生のかん字ドリル",
  kanji: ["三", "四"],
  scoreNote: "80てんいじょうで「よくできました」シールをはろう！",
  footer: "かん字れんしゅうシート ／ 1年生 ／ 三・四",
  sections: [ /* 見下面 */ ]
};
```

四種題型：

```js
// 描紅練習（範字＋畫數＋田字格＋よみかた/つかいかた 卡）
{ type: "trace", points: 20, heading: "□に かん字を かきましょう。",
  cells: 5,        // 每字幾個格子
  guides: 3,       // 前幾格印淡灰描紅字
  rowHeight: 78,   // 選填，一列多高（預設 86）
  cellSize: 46 }   // 選填，格子邊長（預設 53）

// 讀音題：{ } 包起來的字會加紅色底線
{ type: "reading", points: 10, heading: "―の よみかたを ひらがなで かきましょう。",
  items: [ { text: "{三}にん ならぶ。", answer: "さん" } ] }

// 填字題：{} 是空的田字格，hint 是格子上方的振假名
{ type: "fill", points: 10, heading: "□に かん字を かきましょう。",
  items: [ { text: "{}月に なる。", hint: "さん", answer: "三" } ] }

// 自由練習：每字一整排空格
{ type: "free", heading: "じぶんで なんかい も 書いてみましょう。", cells: 9 }
```

#### 一頁能放幾個漢字

A4 塞得下的量是固定的，超過就會被裁掉。實測：

- **2 個字**：四個大題全放得下（小一版就是這樣）。
- **4 個字**：要拿掉「自由練習」大題，並把 `rowHeight` 降到 78（N3 版就是這樣）。
- 想再多就得縮 `cellSize`，但格子太小就不好寫了。

改完務必在瀏覽器裡確認沒有溢出——`.sheet` 是 `overflow: hidden`，
超出的內容會被**無聲裁掉**，不會有任何錯誤訊息。

### 3. 筆順資料（可略）

要讓新的字也有筆順動畫，跑一次：

```bash
node tools/fetch-kanjivg.js 三 四 五
```

會從 KanjiVG 抓下來、合併進 `data/strokes.js`（已經有的字會更新，其他字不動）。
只有加字時要跑，需要網路；平常開網頁完全不會連外。

### 4. `data/manifest.js` — 目錄

```js
{ id: "g1-07", grade: 1, label: "れんしゅう ⑦", kanji: ["三", "四"] }
```

## 檔案結構

```
nihonngo/
├─ index.html            目錄頁
├─ sheet.html            練習單

├─ data/
│  ├─ kanji.js           漢字字庫

```

## 字型

手寫範字的字型順序是：

1. `UD デジタル教科書体 NK-R` — Windows 10/11 內建的教科書體，離線也有
2. `Klee One` — Google Fonts 的楷書風，第 1 個沒有時用
3. 系統明體

網頁字型從 Google Fonts 載入。**離線使用時**會退回系統字型；如果系統沒有日文字型，
部分漢字會顯示成中文字形（例如 `直`、`令`、`骨` 的寫法不同）。要完全離線，
可以把字型檔下載到 `assets/fonts/` 再改 `css/sheet.css` 裡的 `--font-write`。
