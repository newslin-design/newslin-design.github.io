## 一、產品定義（PRD）

### 產品概觀
會議上的「即時翻譯」與「會議紀錄」運算設備。

> ⚠️ **更正**：實際產品**直接串接微軟 STT 服務（含翻譯）**，並非自建「語音→分段→GPT 翻譯」管線。撰稿一律以此為準。
> Figma 原文（僅存參考）：語音 → 分段文字 → GPT 翻譯 → 字幕 or 語音 → 會議記錄 / 會議總結

**主功能（更正後）：影音接入 → 串接微軟 STT 服務（即時轉錄＋翻譯）→ 疊加雙語字幕輸出 → 會議記錄 / 總結**

### TA / 使用情境
- 中大型研討會的翻譯與會議紀錄系統
- ~~小型會議的翻譯與會議紀錄系統~~ → **後續排除**（情境盤點判定不合理、更適合純翻譯/總結 SaaS，見第二節）
- 活動公關公司

### 情境所需功能
- **中大型研討會的翻譯與會議紀錄系統** — 多語言字幕與會議畫面融合輸出顯示
  - for Remote Meeting → UVC-out 畫面+字幕（給遠端）、HDMI-out 控制畫面（給會議主持人）
  - for Hybrid Meeting → HDMI-out to ProAV 畫面+字幕（給遠端+現場畫面）、控制畫面（給會議主持人）
- **小型會議的翻譯與會議紀錄系統**（⚠️ 後續排除）— 使用流程：開始會議 → 輸入會議設定選項 → 錄音顯示雙語字幕 → 會議結束 → 總結 + 輸出會議記錄 + Tag 會議重點/代辦事項；輸出會議記錄、檔案儲存至電腦、自動郵寄
  - SOHO 使用：容易被 SaaS 取代，不建議 → **此情境經評估後刻意排除**（見第二節）
- **活動公司／翻譯公司（導播）** — 可融入既有導播體系；可輸出去背或單色畫面；可輕鬆搭配 OBS 等導播程式（過於偏軟體也可能容易被比較）

### 產品優勢與定位
- **核心：讓場域無痛長出 AI** — 多功能、可自由設定，方便 SI 依場域一鍵導入專屬 AI 服務，並與 ATEN 既有環控、專案影音設備整合（不打 AI 功能戰，打整合戰）
- **隱私解法**：資料一定上雲，但可規劃走企業自有的信任供應商（如 Microsoft / Azure）——讓可能含機密的會議資料留在公司原本就信任的體系內，不外流第三方 SaaS（取代「離線＝隱私」的舊框架）
- 翻譯較精準（受分段文字等因素影響，需再加強）
- 可配合 ATEN 其他產品，讓會議室新增 AI 翻譯功能
- 具體優勢：方便業務把原先的會議室解決方案加上 AI 功能；有 Port 方便串接 ATEN 產品或環控；與 ATEN 產品整合性高；可溝通調整 AI 模型
- 配合現有業務已在賣的 RBS 會議系統，同步公司各房間機台、整合會議行事曆與人員、自動發送會議紀錄
- 搭配 ProAV 系統，得知不同麥克風來源以分辨不同講者

## 二、Use Case 使用情境

四大情境分群（皆標註 *AI Meeting Edge Scenario*）：個人/小型會議、活動/導播、中大型研討會、遠端會議。

### Use Case A：有主講者研討會
開始準備 → 開啟新會議 → 工作人員測試（聲音/收音、畫面、翻譯）→ 等待觀眾到達 → 開始研討會
- 為現場觀眾翻譯字幕
- 為遠端觀眾翻譯字幕 → 用遠端會議軟體更適合（Teams）
- 研討會類型：單一講者 / 多講者 → 能否用不同麥克風辨別講者？
- 觀眾互動（QA）：觀眾須拿麥克風才能收音 → 能否用不同麥克風辨別講者？翻譯觀眾說話內容
- 結束會議 → 產生逐字稿與翻譯；字幕與現場（或導播）畫面合併輸出為全程字幕影片；依重點時間 TAG 於正確斷句點剪輯，製作精華影片

### Use Case B：一般會議
進入會議室 → 開啟新會議（可從行事曆 RBS 自動帶入會議資訊？從上次相同會議帶入資訊？）→ 等待人員到齊 → 開始會議
- 待討論事項、前次會議摘要、前次代辦事項 Check
- 產生翻譯與字幕；可暫停、重開會議
- 討論代辦事項、分配工作
- 討論型態：單一報告 / 多人討論 / 多小組同時說話
- 結束會議 → 觀看、檢查、修正會議記錄（逐字稿）；產出總結/重點/代辦事項並選擇是否修正；輸出影音檔（帶字幕）；發送至指定成員信箱或資料夾
- 會議結束後的會議紀錄觀看安全性（或選擇不保存）

### 場景配置矩陣（螢幕 / 訊源 / AI 裝置）
- 大型研討會 01：使用 AI 邊緣運算；單螢幕研討會
- 大型研討會 02：使用 總結 SaaS；主持人翻譯字幕
- 螢幕：多螢幕（放大講者頭像）／ 單一螢幕（簡報 + 字幕）
- 運算：AI 邊緣運算（AI Edge + PC(PPT) + USB MIC）／ PC(PPT + SaaS) + USB MIC
- 字幕輸出：僅播放字幕（多國語言）／ 僅播放字幕
- 圖示角色：Source、AI Device、Output Display

## 五、Demo 流程（展場 DEMO）

展場 DEMO：人聲與畫面（a Video / UVC-in）；控制方式：鍵盤；雙畫面展示。

1. 開始會議 → 選擇會議主題、語言、字幕模板
2. 開始錄音 → 開始翻譯 + 合成字幕
3. 會議中：持續錄音、翻譯合成字幕
   - 主畫面：輸入畫面 + 字幕（模板）
   - 控制端：顯示完整中英字幕、可下時間 TAG（往前幾秒）、重點、分段
   - 總結前可輸入主題或自動產生主題、代辦清單、分段總結（會議中即時總結）
4. 會議結束 → 關閉錄音/字幕 → 開始總結 → 發送會議紀錄（總結或逐字稿）→ 回播內容
