ATEN Solution Builder

2023 - 現在

透過數位工具驅動企業轉型：
從單純銷售產品走向提供完整解決方案

本案例研究將解構 ATEN Solution Builder——一個催化 ATEN 從「產品導向」銷售模式， 戰略性轉型為「解決方案導向」的關鍵專案。

作為主導的產品設計師與使用者體驗工程師 (UX Engineer)，我將詳述我們如何將一個複雜的商業挑戰， 轉化為無縫的數位體驗，最終驅動可衡量的營收增長與營運效率。

UX/UI 設計、前端開發 (React)、數據分析架構

核心貢獻

從 0 到 1 打造工具：設計並開發視覺化連線圖模擬器， 取代傳統繁瑣的 Excel/Visio 規劃流程。

商業模式轉型：協助公司從單一產品銷售 (Product-Oriented) 轉型為場景解決方案提供者 (Solution-Oriented)。

數據閉環：建立從前端行為數據 (GA4) 到商業智慧 (PowerBI) 的分析架構，驗證設計成效。

本專案不僅是一個工具的開發，更是推動企業戰略轉型的關鍵引擎。 接下來，我們將深入探討其背後的商業挑戰與策略。

背景挑戰與策略

剖析商業痛點與使用者需求

任何成功的產品都始於對商業環境與目標受眾的深刻理解。 本章節將解構 ATEN 所面臨的核心挑戰，並闡述我們為此制定的，以使用者為中心的設計策略。

商業轉型的十字路口

在專案啟動之初，公司正處於關鍵的轉型期，面臨兩大商業挑戰：

1. 市場脫節

過去高度依賴經銷商進行單一產品銷售的模式，導致公司難以掌握終端客戶的真實需求與行為數據。 這種隔閡不僅壓縮了產品毛利，也限制了客戶忠誠度的培養。

2. 提案門檻高

專業影音 (Pro AV) 系統的架構極其複雜，新進業務人員或系統整合商 (SI) 需要經歷漫長的學習曲線才能獨立完成一份專業提案，直接導致了銷售週期的延長與效率的低落。

UX 的戰略定位

面對上述挑戰，UX 的角色不再僅限於介面優化，而是成為驅動營收增長的戰略核心。 我們的關鍵命題是：

「如何降低 SI 的提案門檻，並提升提案成功率？」

Solution Builder 便是我們給出的答案——一個旨在將複雜系統規劃流程 標準化、視覺化與自動化的數位工具。它不僅解決了效率問題，更成為公司直接觸及終端使用者、 推動解決方案銷售模式的戰略支點。

目標受眾與分層設計策略

為了確保產品能精準滿足不同使用者的需求，我們定義了三類核心目標族群， 並為其量身打造了分層的設計策略：

菜鳥 / 陌生 SI

痛點

不熟悉產品線，不知道如何搭配產品，提案缺乏信心。

策略：引導式場景模板

設計了精靈般的引導式體驗，將產品的複雜性抽象化。使用者只需回答關於應用場景的簡單問題， 系統便會生成一份有效的方案草圖，讓新手有一個有意義的起點，而非面對空白畫布從零摸索。

老手 / 高價值 SI

痛點

追求極致效率，需要快速處理複雜架構與驗證相容性。

策略：高自由度畫布與即時驗證

提供無限制的拖放式畫布，並嵌入相容性引擎，能對連線提供即時反饋， 讓專家能快速建構原型並為複雜的客製化架構排除風險。

子公司 / 內部業務

痛點

需快速回應中小型案件，並減少內部教育訓練的成本。

策略：自動化提案生成

系統能自動化最後一哩路，生成包含物料清單 (BOM) 與系統架構圖的完整文件， 讓銷售團隊從繁瑣的文書工作中解放出來。

產品功能與設計細節

核心功能深度解析

這些功能經過精心設計，旨在徹底顛覆傳統、耗時的類比工作流程，重塑為直觀、智慧的數位化體驗。

功能一：視覺化拓撲編輯器

應用程式的核心

一個功能強大的視覺化畫布，讓使用者能像在白板上作畫一樣輕鬆地建構系統架構。

技術基礎

採用 React 框架，並基於 @xyflow/react 函式庫深度客製化開發。

直觀操作

使用者可透過簡單的拖放操作，從右側的設備庫中將產品圖示放置到畫布上，快速佈局。

豐富的編輯工具

設備圖示：提供四種不同尺寸 (Full Detail, L, S, T)，可根據圖表複雜度自由切換。

設備標籤：獨特的彩色邊框系統，將設備標記為核心（橘色）、主要（藍色）、 輔助（綠色）、待解問題（紅色）等不同重要性級別。

輔助圖形：內建多種註解工具與背景圖形，幫助使用者製作出專業且具備高可讀性的系統圖。

智慧連線

使用者只需在設備的連接埠之間拖曳即可建立連線。系統會依訊號類型自動為線條上色 （影像：藍色、音訊：粉色、網路：淺藍色等，沿用 ATEN 既有的訊號色彩規範），讓圖面一眼可讀。

功能二：彈性的專案創建流程

雙路徑設計，適合所有技術水平

從模板開始

提供類似精靈 (Wizard) 的引導式體驗。使用者可選擇預設的應用場景如「會議室」或「教室」， 系統便會自動生成預先配置好的連線圖，使用者只需微調即可完成。

模板庫已累積 2,000+ 組模組化模板，內容由產品企劃透過後台持續上稿維護； 我負責的是讓上稿變容易的工具與資料結構，確保模板能隨產品線更新，而不需每次找工程改 code。

從零開始

針對資深專家，提供完全空白的畫布，不受任何限制地設計高度客製化的解決方案。

功能三：自動化文件產出

將提案流程的最後一哩路完全自動化

BOM 表生成

「Export BOM」功能可一鍵將畫布上所有產品及其數量匯出為標準的 Excel 物料清單。

系統架構圖匯出

「Export Diagram」功能可將當前畫布內容生成為一份專業的 PDF 文件，可直接用於正式提案。

智慧 BOM 計算

BOM 表的計算會精確地考慮到「群組」節點內的設備數量（含倍數），並自動過濾被標記為「隱藏」的節點。

技術實踐與工程貢獻

跨越設計與開發的邊界

作為一名 UX 工程師，我的貢獻不僅在於勾勒設計藍圖，更在於親手將其化為現實。 本章節將詳細介紹我在專案中承擔的關鍵工程任務。

工程一：前端架構與元件化開發

建構模組化、可擴展的系統

技術選型

React 核心框架 + Ant Design UI 元件庫 + @xyflow/react 視覺化圖表編輯。

自訂節點元件

為畫布上的核心元素創建了高度客製化的 React 元件（DeviceNode、GroupNode）， 將畫布上的節點從靜態圖示轉變為智慧的、自我包含的代理。

性能優化

面對數千個設備的產品庫，透過批次請求的懶加載策略， 確保應用在數秒內即可互動，同時完整的設備庫在背景中無縫加載。

工程二：AI 驅動的產品資料統一化

用 LLM 解決遺留數據瓶頸

問題定義

數十年來的舊有產品規格僅存在於非結構化、不一致的 HTML 表格中，無法被現代應用程式使用。

解決方案

開發 Node.js 腳本自動化數據清洗與結構化， 利用 OpenAI API (GPT-4o) 將雜亂的產品規格表轉換為乾淨、統一的 JSON 格式。

精密提示工程

設計了詳盡的 Prompt，包含嚴格規則用以處理各種複雜情況： 解析數量詞 ("2 x HDMI")、準確分類連接埠類型、正確識別訊號延伸器等特殊設備。

工程三：複雜功能的實現巧思

工程亮點

原子化 BOM 下載

使用者點擊下載時，系統在後端即時創建臨時專案，計算 BOM 並匯出 Excel，然後立即刪除臨時專案。 提供直接下載的即時滿足感，同時避免在工作區中產生孤立的臨時專案。

批次自動化處理

handleBatchProcess 函式能自動生成模板所有選項的排列組合，並對每一種組合執行一系列自動化動作， 為內部團隊大規模管理和維護模板提供了極大的便利。

成果驗證與商業影響

數據驅動的價值衡量

我們建立了一條可量化的直接連結，將使用者參與度和核心商業成果（如潛在客戶生成和銷售轉換）聯繫起來。

定義成功指標

效率提升

將原本需要翻規格書、人工計算線材、整理 BOM 的提案流程大幅縮短，把資深 SI 的時間從重複勞動移回真正需要專業判斷的環節。

行銷與銷售漏斗

獲客：工具本身成為強大的潛在客戶磁鐵，吸引大量新的系統整合商註冊使用。

留存：追蹤高價值 SI 用戶的平台參與度和回訪率，衡量產品黏著度。

營收轉換：系統能將模擬器中的草稿圖直接轉化為 Salesforce 中的銷售商機。

建立數據反饋閉環

數據架構

前端 GA4 追蹤 → BigQuery 儲存分析 → PowerBI 整合 CRM 銷售數據。

洞察與行動

市場需求洞察

分析大量連線圖數據後，發現市場上最受歡迎的產品組合，直接促使行銷部門推出針對性的「產品組合包」銷售活動。

產品研發指引

發現使用者頻繁使用第三方解決方案來彌補功能空缺，將這些「缺口訊號」反饋給研發團隊，作為新品立項評估的具體依據。

專案總結

不只是工具——更是商業轉型的催化劑

ATEN Solution Builder 不僅僅是一個軟體工具，它更是一個推動商業模式轉型的核心載體。 這個專案充分展示了一名 UX 工程師如何融合商業策略思維、 穩健的前端開發技術以及數據驅動的洞察力， 將一個複雜、傳統的硬體銷售流程，轉化為流暢、高效的數位化體驗。

最終，Solution Builder 為 ATEN 與客戶的互動方式建立了新的典範， 證明了設計與工程的深度融合不僅能解決使用者痛點，更能從根本上重塑公司的市場策略，創造持久的商業影響力。
