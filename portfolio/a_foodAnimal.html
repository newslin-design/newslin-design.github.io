Food Animal Personality Quiz

Side Project

"Can the way we eat reflect who we are?"

It started from a casual chat during a colleague's birthday lunch — everyone's food preferences were so different that we wanted to build a dining personality quiz to explore it. It also seemed like a good chance to see whether one person could use Generative AI to handle the entire process: planning, illustration, and frontend development.

Three things needed to be figured out along the way:
• Logic design: Built a four-dimension scoring model inspired by MBTI, replacing random results with structured reasoning.
• Visual consistency: Iterated on Midjourney prompts to keep all 16 character illustrations in a unified style.
• Frontend implementation: Used a JSON-based weight system to manage questions and scoring, paired with HTML/JS for a responsive interactive page.

Design Decisions

The core question for this project was: how to make a "dining personality quiz" feel accurate enough that people want to share their results? Here are the three main design decisions.

Three Design Decisions

1. Represent Personalities as Animals

Quiz results map to specific animal personas (e.g., Strategist Elephant, Comfort Cat). Animals are easier to remember than abstract adjectives, and easier to bring up in conversation.

2. A Signature "Inner Monologue" for Each Character

At the top of each result page is a short character quote (e.g., Ritual Swan: "Regarding the order of desserts, I have an Excel spreadsheet that can explain it."). The goal is to give people an immediate "that's so me" reaction, which also makes it easy to screenshot and share.

3. Dining Buddy / Dining Disaster Pairing

Each result shows a "best dining buddy" and a "worst match", extending the experience from "viewing my own result" to "tagging friends" — adding a layer of social interaction.

Research & Logic Framework

Translating "Taste" into "Personality"

To avoid the quiz feeling like random guessing, I introduced an MBTI-inspired framework, translating vague dietary preferences into a quantifiable "four-dimension model."

The Four Dimensions of Dining Personality

Taste vs. Idea

Do you eat for physical deliciousness or story and atmosphere?

Social vs. Lonely

Is dining about connecting with others or recharging yourself?

Deep-rooted vs. Experimental

Faced with "Cilantro Century Egg Pizza" — do you defend Italian dignity, or get excited to try it?

Methodical vs. Free-flowing

When ordering, do you calculate nutritional ratios, or go with the moment's mood?

Question Design Example

Scenario: A popular dessert shop has two new items — which do you pick?

A. Chocolate donut — tried it many times, definitely delicious! 🍩
→ Deep-rooted [0, 0, +1, 0]

B. Chili cheese puff — never tried this flavor! Let me taste it 🌶️
→ Experimental [0, 0, -1, 0]

Content Engineering

From Logic Labels to Character Copy

The 16 personality codes are just dry classification labels on their own — they needed to become character descriptions with actual personality. The approach was to use Prompt Chaining, having the LLM write drafts in the voice of a "food critic," then I adjusted the tone and removed inconsistencies one by one to make sure all characters read coherently.

Visual Consistency System

Making 16 Images Look Like One Set

The most common issue with Midjourney is that each generated image comes out in a slightly different style. To make all 16 result cards look like they belong to the same illustrated guide, I iterated on prompt parameters and eventually settled on a "Sumikko Gurashi style" anchor to bring them together.

Prompt Engineering Key Parameters

Style Anchor: pastel sketchy style, minimalist graphics, bold outlines.

Atmosphere: Clean solid warm cream background (ensuring easy clipping and layout composition), soft lighting.

Character-Specific Fine-tuning

Comfort Cat (Slow-Warm Cat)

Blended pastel soft koala roundness traits, adding "curled up in a kotatsu blanket" to reinforce the "homebody" attribute.

Hedgehog Soloist

Added "clean lab-like setting" and "reading nutrition label" — making visual details echo the character profile.

Technical Execution

Frontend Development & AI Collaboration

I defined the architecture and logic, then used AI (Copilot/LLM) to help write the implementation code.

Data Structure Design (JSON Schema)

I designed a weight-based scoring system where each question's options dynamically affect scores across four dimensions.

Interactive Logic Implementation

Dynamic Weight Calculation

Real-time array score computation on the backend, ultimately mapping to the corresponding personality key (e.g., TSDM = Strategist Elephant).

Social Matching Algorithm

Logic to determine compatible (Dining Buddy) and incompatible (Dining Disaster) combinations. For example, the logic-driven "Ritual Swan" and the intuition-driven "Party Pup" are set as incompatible.

Overall Workflow

Phase 1: Logic Architecture

(Human) Define problem & goals, establish the "four-dimension dining psychology" model inspired by MBTI.

(Output) 16-personality logic skeleton.

Phase 2: Parallel Production

Track A — Content: Prompt Chain design → AI generates 16 personality drafts → Human-in-the-loop refinement → Final copy & JSON.

Track B — Visual: Set visual anchor → Prompt stress testing → Midjourney generation → Fine-tuning → 16 consistent character cards.

Phase 3: Full-stack Integration

(Human) Design scoring weight system & social matching algorithm.

(AI - Copilot) Pair programming for JavaScript logic & CSS.

(Output) Final product: RWD interactive web app.

Reflection

Takeaways

This project gave me a more concrete sense of how the focus of a designer's work shifts when collaborating with AI.

Output Gets Faster, Judgment Gets More Important

AI can generate large amounts of copy and images quickly, but deciding "which ones work and which don't" still falls on the human side. Filtering and refining took a significant portion of the time.

The Development Cycle Did Get Shorter

From planning to launch took roughly a few days. The time saved went into adjusting interaction details and testing the experience.

Overall, this project was a fairly complete run of AI-assisted work — from logic, copywriting, and visuals to frontend. Going through the entire process solo also made it clearer which parts AI can help with and which still need to be done by hand.
