# 織圖 SVG 出圖規格（角色區「哨兵色」制）

> 目的：讓「哪塊是醬料 / 配料1 / 配料2」由**你在 Figma 畫的區塊**明確決定，不再靠程式猜；
> 且 2D 織圖與 3D 麵條讀**同一份區塊定義**，保證兩邊一致。

## 一、三個角色，三個固定「哨兵色」

在 Figma 把角色區塊**平塗**成以下純色（程式會把這些色換成當前訂單的實際顏色）：

| 角色 | 哨兵色（純色平塗） | 說明 |
|------|-------------------|------|
| 醬料 sauce | `#E9E4DB`（暖米灰） | 通常是鋪滿的底 |
| 配料1 top0 | `#F3E9E9`（淡粉灰） | 第一種配料的環帶 |
| 配料2 top1 | `#FFFEFE`（近白） | 第二種配料的環帶 |

- 這 3 色是**佔位色**，玩家永遠看不到——上桌時會被換成訂單的醬料/配料色。
- 這組是柔和近白色（你選的），三色彼此很近（醬料↔配料1 只差 18）、`#FFFEFE` 又很接近白底。程式已用**「標記遮罩」**處理：偵測 3D 環帶時把色塊暫換純紅/綠/藍再判讀，所以能安全用這種柔和色。
- **關鍵限制**：這三個 hex 必須**精確填入**（用 Figma 的 hex 輸入，別用滴管吸色造成漂移）；也別再用其他「近白」色當作別的東西。容差在 `config.js` 的 `ZONE_SENTINEL_TOL`（目前 10）。
- 若日後想換更好認的色，改 `config.js` 的 `ZONE_SENTINELS` 一處即可（單一來源），SVG 跟著改成新色。

## 二、必須畫成「同心環帶」

3D 麵條是螺旋管、**只能用「距圓心的半徑」表達顏色**。所以角色區要畫成**一圈一圈的同心環**，2D 與 3D 才會完全一致。

- 圖形**置中**：圓心對準 viewBox 正中央（如 1024×1024 → 圓心 512,512）。
- 每個角色是一條或多條**同心環帶**（甜甜圈狀），半徑範圍不重疊。
- 醬料常見做法：當最外／最內的「底」，配料夾在中間環。實際怎麼分由你決定，但**同一半徑上只能有一個角色**。
- 不要用花瓣狀、放射狀、散點狀來分角色區（那些 3D 還原不出來）。花瓣造型可以放在「線稿層」當視覺，但**角色區塊本身要同心**。

## 三、圖層順序（線稿疊在色塊上）

一張 SVG 內兩種東西：

1. **角色色塊層**（哨兵色平塗的同心環）→ 放**底層**。
2. **針目／線稿層**（毛線鉤織的細節、輪廓）→ 放**上層**，且**背景透明**（不要有整片填滿的底 rect，否則會蓋住色塊）。

程式規則：**fill 命中 3 個哨兵色的路徑 = 角色區塊（會被換色）**；其餘任何顏色的路徑 = 線稿細節（原樣顯示）。所以線稿用什麼深色都行，只要別碰到那 3 個哨兵色。

## 四、Figma 匯出設定

- 匯出格式 **SVG**。
- 不需要設圖層 id / 名稱（程式只認顏色）。
- 建議勾「Outline text」、不要「Include id attribute」也沒關係。
- 檔案放 `crochet_library/`，並到 `js/config.js` 的 `PATTERNS` 加一筆（`file` 指到檔名、`img` 指同一檔當縮圖）。

## 五、檢查清單

- [ ] 圓心置中於 viewBox 正中央
- [ ] 角色區只用 `#FF00FF` / `#00FFFF` / `#FFFF00` 三色平塗
- [ ] 三色都畫成同心環帶，半徑不重疊
- [ ] 線稿層背景透明、疊在色塊層上方
- [ ] 線稿沒用到那 3 個哨兵色

範本檔：`crochet_library/_zones_template.svg`（可在 Figma 開來看區塊怎麼分，或直接當測試織圖跑）。
